# Planning

Project state is kept explicit in these Markdown files, not in agent memory. Keep them short and up to date.

- [`plan.md`](plan.md) – roadmap (phases with status) and decision log
- [`new-ui.md`](new-ui.md) – design and steps of the new UI (roadmap step 5), mockup in [`mockups/`](mockups/)
- [`ideas/`](ideas/) – one file per unscheduled idea or research topic; move it into the roadmap once scheduled
  - [`fast-neighbor-search.md`](ideas/fast-neighbor-search.md) – faster than O(N²) simulation
  - [`thesis-future-work.md`](ideas/thesis-future-work.md) – ideas from thesis chapter 5
  - [`flow-visualization.md`](ideas/flow-visualization.md) – trace lines to show the flow direction
