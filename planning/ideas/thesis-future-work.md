# Thesis future work (chapter 5)

Status: idea

- **Simulation:** 2D SWE + 3D rendering, rigid bodies, no-slip and open boundaries, in-/outflow (rain, rivers).
- **Performance:** WebGPU compute, fast neighbor search (see [`fast-neighbor-search.md`](fast-neighbor-search.md)).
- **Stability:** per-particle smoothing length, artificial viscosity, RK3, tuned time step coefficients.
- **UI:** snapshots / shareable state, parameter warnings, height/speed probes, zoom and pan,
  custom ground and fluid via control points, add/remove particles by click, nicer fluid shader.
- **Integration:** 2D games with dynamic terrain, real terrain/weather data.
